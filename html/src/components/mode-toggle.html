{# The two glyphs are Lucide's `moon` and `sun` paths, inlined: the HTML edition has no bundler and no package to import from, and the React edition's `lucide-react` is the same drawing. Hand-rolling an icon is a bug; copying the set's own path data is not. ── A DECLARED DIVERGENCE FROM THE REACT EDITION ───────────────────────── React ships a two-button group (`Dark` | `Light`) with `aria-pressed`, because a single button reading "dark" is ambiguous about whether it names the state you are in or the one you would get. This edition ships **one button**, and resolves that ambiguity a different way: the label names the destination in words — "Switch to light" — which is unambiguous without needing a second control to compare against. Both labels are in the document and CSS picks one off `html.light`, so the button is never briefly wrong on a slow load and the swap costs no script.
